**2026-11-19.** نجحت دورة مصدر عام فعلي → StoreProvider → خدمة المزامنة المشتركة → PostgreSQL → REST → Flutter، مع تحقق بصري على Android. بقي تحقق الوصول إلى صفحات البائع عبر redirect لدى CheapShark غير مكتمل بسبب 403 من عميل الفحص. لا نشر أو مرحلة ثامنة أو ادعاء جاهزية إنتاج تجاري.

## الوصول الفعلي والنتائج

راجعت الوثائق الرسمية ونُفذت طلبات محدودة قبل تطوير المزودين. CheapShark أعاد HTTP200 و 35 متجرًا و 20 عرضًا، و GamerPower أعاد HTTP200 وخلاصة 101 عنصر دون حساب أو مفتاح. المصدران منفصلان عن البائع؛ لا بيانات Mock مقدمة على أنها فعلية.

| ---------- | ------------------------: | -----------------------: | ------------: | -------------------------------------------------------------------------------------------- |

آخر جولتي مصدر فعليتين مسجلتان عند **14:41 UTC**. طلب CheapShark الأول احتاج طلبَي HTTP للمتاجر والعروض، والثاني طلب عروض واحدًا؛ GamerPower طلب خلاصة واحدًا لكل جولة. الجولات محدودة بصفحة واحدة و 20 عنصرًا، لذا `PARTIAL / PAGE_LIMIT` **حد مقصود** وليس اكتمال الكتالوج أو خطأ مخفيًا. لم يُشغّل زحف كامل أو عامل تجاري دوري.

في التحقق النهائي عند **14:43 UTC** أعاد REST أربعين عرضًا صالحًا، دون أي synthetic. إجمالي الصفوف 47، منها 7 عينات GamerPower سابقة انتهت وحُجبت؛ لم تُحذف بيانات التطوير لإجبار الأعداد على التطابق. احتفظت قاعدة التطوير بمنتجاتها الاصطناعية السابقة **19 منتجًا و 16 عرضًا** دون تغيير.

## التصميم والترحيل

أُعيد استخدام Registry و OfferIngestionService و ProductSynchronizationService و BackgroundWorker والتقييم الحالي. لا قاعدة أو خدمة مزامنة مستقلة لكل مصدر، ولا تبعيات جديدة.

ترحيل إضافي واحد **20261119150000_real_sources**، دون تعديل الترحيلات الست السابقة أو حذف بيانات: قيمتا SourceType جديدتان، وعلم Merchant.isDataSource، وعلاقة ذاتية dataSourceId مع externalStoreId فريد داخل المصدر، و websiteUrl اختياري لأن أسماء متاجر CheapShark لا تأتي بمواقعها. أضيف Offer.sourceMetadata المحدود والمتحقق منه لحفظ المصدر والإسناد والمنصة والنوع ونص النهاية والانتهاء المحافظ. تبقى SyncRuns والأقفال موزعة على مصدر المزامنة.

يربط عرض CheapShark البائع الحقيقي بهوية gameID ثابتة؛ يبقى dealID المتغير للرابط فقط. يجمع المنتج بين البائعين داخل المصدر نفسه بدليل gameID وتحت قفل معاملاتي؛ لا دمج بالأسماء أو بين مصدرين. سحب موافقة المصدر يحجب العروض التابعة عبر مسارات ORM و SQL. انتهت مقارنة Schema بالقاعدة بـ **No difference detected** بعد التصريح بـonUpdate:NoAction المطابق للترحيل. أصبحت 7 ترحيلات مطبقة على التطوير والاختبار المستقل.

GamerPower بلا صفحات رسمية: خلاصة واحدة ثابتة داخل الجولة تُقسم محليًا، ولا يستأنف مزوداهذه المرحلة Checkpoint منجولة سابقة. لا يحول فشل مصدر إلى حذف جماعي. TTL يحدد نهاية صلاحية الكاش، و Expiry يحدّث الواجهة حتى أثناء بقاء الشاشة مفتوحة. تبقى صيانة الحذف بحاجة إلى تشغيل العامل أو الأمر اليدوي؛ لا عملية تلقائية أثناء إغلاق البرنامج.

## صور التطبيق الفعلية

يتحقق اختبار Registry أيضًا من تبديل المزود عند تغير نوع المصدر أو اسمه، ويثبت اختبار BackgroundWorker الجديد اختيار المصدر المصرح وحده في وضع الإنتاج ومنع مزامنة synthetic، مع HTTP Mock وقاعدة اختبار مستقلة. اختُبرت أوامر العينة المستقلة قراءة فقط: عنصران منCheapShark وعنصر منGamerPower. بعد الفحص أُغلق خادم QA وأُوقف المحاكي الذي شُغل للاختبار، دون حذف بياناته أو إغلاق برامج المستخدم.

## التشغيل والسياسات والقيود

راجع [DATA_SOURCES](DATA_SOURCES.md) للأوامر، و[CheapShark](CHEAPSHARK.md) و[GamerPower](GAMERPOWER.md) للمراجع الرسمية والسياسة. المصدران مغلقان افتراضيًا للعامل؛ المزامنة اليدوية opt-in للعملية ولا تعدل`.env`. CheapShark يدوي محدود فقط، و GamerPower يمكن تفعيله اختياريًا كل 300 ثانية. لا تشغيل Worker مع Express. واجهة Flutter افتراضيًا للبيانات الحقيقية، و Backend يحجب synthetic افتراضيًا حتى في التطوير، مع استثناء Demo صريح لا يعمل في الإنتاج.

الاحتفاظ التشغيلي 1800/600 ثانية، وليس مدة ترخيص مفترضة. يلزم إسناد فعال لـGamerPower وروابط CheapShark الرسمية؛ لا Affiliate خاص أو إعادة بيع بيانات أو Scraping أو أرشيف سعر دائم. المنطقة الزمنية لنهاية GamerPower مجهولة؛ الحساب المحافظ قد يحجب العرض مبكرًا. السوق والتوفر الإقليمي غير معروفين؛ اترك All markets للعينات، وتحقق من الأهلية في صفحة العرض.

**قيد الرابط:** أعادت روابط GamerPower الرسمية 301 إلى Epic Games Store وفي عينة أخرى إلى IndieGala، دون متابعة استرداد أو شراء. رابط CheapShark الرسمي أعاد 403 لعميل HEAD و GET مع نجاح API200. لا نجزم بسبب 403 أو بنجاح متصفح المستخدم، ولم نتجاوز الرد أو نستبدل الروابط؛ يبقى تحقق الوصول إلى البائع عبر CheapShark مفتوحًا.

العامل الدوري لم يُترك مشغلًا. توقف خادم قبول QA3337 بعد اختبار المحاكي؛ استخدم`npm run dev` وإعداد Flutter على 3000 للتشغيل المعتاد. APK الاختبار المثبت مضبوط على 3337، لذا شغّل خادم QA الموثق له أو أعد`flutter run` على 3000. تتطلب العينات تحديثًا بعد انتهاء TTL، ولا يُبقى المنتج ظاهرًا باصطناع بيانات جديدة. إعداد DB المحلي superuser وقيود الأداء من 6.1 باقية؛ لم تُعد اختبارات الحمل أو تُرفع مهلها.
