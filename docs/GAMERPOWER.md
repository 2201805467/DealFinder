# GamerPower — المرحلة السابعة

مراجعة الوثائق والاتصال الفعلي: **2026-11-19**.

## الإذن والحدود الرسمية

[توثيق API وشروطه](https://www.gamerpower.com/api-read) يسمح بتطبيقات شخصية وتجارية وموبايل دون حساب أو API Key، ويلزم **إسنادًا برابط فعال إلى GamerPower**. لا يجوز ادعاء ملكية البيانات أو إعادة بيعها دون إذن. [شروط الموقع العامة](https://www.gamerpower.com/terms-of-use) تتضمن قيودًا عامة على محتوى الموقع وتقر شروط الخدمات الإضافية؛ التكامل يستخدم API المصرح به فقط، دون Scraping صفحات الموقع.

السقف المنشور 10 طلبات/ثانية. العميل أبطأ بكثير، بتباعد≈1.1 ثانية، وطلب خلاصة واحد لكل دورة. الفاصل الافتراضي 300 ثانية عند التفعيل الصريح.429/Retry-After ومهلة 10s وإعادة المحاولة المحدودة يعالجها HTTP والعامل الحاليان.201 يعني عدم وجود giveaways وليس خطأ JSON.

## ما تدعمه API وما ينفذه المزود

`GET /api/giveaways` للخلاصة، و`/giveaway?id=...` لتفاصيل عنصر. توجد platform/type/sort-by و`/filter` للدمج، لكن هذه المرحلة لا تحتاج طلب تفاصيل لكل عنصر. **لا Pagination رسمية**: ينزل المزود خلاصة JSON محدودة 4MiB و 5000 عنصر كحد دفاعي، يثبتها أثناءالدورة ثم يقسمها محليًا، معبحث محلي بالاسم. لا يعيد تنزيلها لكل صفحة ولا يستأنف Checkpoint قديمًا في دورة جديدة.

تختلف قيمة الاستجابة عن اسم المرشح: مرشح type=loot لا يعني أن حقل type سيحتوي"Loot"؛ التحقق الحقيقي وجد Game و DLC و Early Access و Other. اختبارات Mock تغطي ذلك.

| حقل المصدر               | المعنى داخل DealFinder                                                                |
| ------------------------ | ------------------------------------------------------------------------------------- |
| id / title / description | هوية خارجية واسم ووصف، مع تحقق الأطوال                                                |
| image / thumbnail        | رابط صورة API دون إعادة استضافة ملفاتها                                               |
| worth                    | قيمة تقديرية USD؛ لا تخزن كسعر أصلي موثوق ولا يحسب منها خصم 100%                      |
| status                   | يقبل Active فقط؛ غير المتاح لا يُعرض كهدية قابلة للاسترداد                             |
| type                     | Game→game، DLC→dlc، Early Access→beta، Other→giveaway غير محدد، و Loot→loot عند وروده |
| platforms                | قائمة منصات الاسترداد، ليست اسم البائع ولا دليل إتاحة عالمية                          |
| end_date                 | انتهاء المصدر مع النص الأصلي؛N/A يبقى مجهولًا                                          |
| published_date           | تاريخ نشر المصدر، ليس تاريخ الجلب أو ضمان حداثة السعر                                 |
| open_giveaway_url        | رابط GamerPower الرسمي `/open/…`؛ لا يستبدل برابط Affiliate خاص                       |

السعر الحالي0 لأن الخلاصة للهدايا المتاحة مجانًا؛ تعرض الواجهة **Free** مع نوع المحتوى. لا تعني كل هدية لعبة كاملة؛ DLC وloot منفصلان. البائع غير محدد في هذه الخلاصة، لذلك يسمى صراحة **Giveaway publisher not specified**، وموقعه والسوق فارغان. يظهر مصدر البيانات بصورة مستقلة مع رابط الإسناد في البطاقة والتفاصيل. طلب discountedOnly يعيد قائمة فارغة، لأن Worth لا يثبت خصمًا موثوقًا؛ لا تُعامل الهدية تلقائيًا كخصم100%.

لا تحدد الوثائق المنطقة الزمنية لنص end_date. لا نضع Z على النص وندعي UTC؛ نستخدم أبكر انتهاء UTC محتمل، بإزاحة14 ساعة من تفسير النص كوقت UTC، ونظهر النص الأصلي مع التنبيه. قد يحجب ذلك عروضًا قرب نهايتها قبل انتهائها الفعلي. النصوص غير الصالحة تُستبعد، وN/A يعتمد TTL فقط. انتهاء البيانات في DB هو الأقرب من انتهاء المصدر وTTL، وتميز الواجهة ذلك عن وقت نهاية الهدية المعلن.

## الاحتفاظ والصور

لا تحدد صفحة API المقروءة مدة احتفاظ أو ترخيص إعادة توزيع مستقل للصور. يستخدم المشروع TTL **600 ثانية**، مطابقًا لرأس cache-control المرصود؛ هذا اختيار تشغيلي محافظ وليس مدة قانونية منسوبة للمصدر. لا تاريخ أسعار أو نسخ ملفات صور أو Dataset قابل للبيع. تعرض الصور بروابطها الأصليةضمن العرض مع الإسناد وتبقىحقوقها لأصحابها. يحجب TTL النصوص والصور والأسعار المنتهية، ويحذف التنظيف المحتوى المنتهي. دون تشغيل العامل أو أمر التنظيف تظل صفوف منتهية محجوبة في القاعدة حتى الصيانة التالية؛ لا نعد بحذف أثناء إغلاق التطبيق.

## التشغيل

من `backend`:

```bash
npm run gamerpower:sample -- --confirm --limit 20
npm run gamerpower:sync -- --confirm --limit 20
```

`--confirm` إذن صريح بطلب فعلي؛لا يستبدل موافقةالمصدر ولا يضيف مفاتيح وهمية. العينة لا تكتب DB. المزامنة تهيئ السياسة عند الحاجة ولا تعيد منح إذن مسحوب. لا يغيرالأمر`.env`.

الجدولة الاختيارية من Git Bash، دونتشغيلها افتراضيًا:

```bash
WORKER_ENABLED=true WORKER_ALLOW_SYNTHETIC=false GAMERPOWER_ENABLED=true npm run worker:real
```

الإعداد الافتراضي 200 منتج و 10 صفحات و 20 طلبًا، كافٍ للخلاصة المرصودة. يمكن خفضه؛الجولةالمحدودة PARTIAL ولا تدعي اكتشافكل العروض. الجولات التالية تبدأ خلاصة جديدة، وفترةالمصدر 300 ثانية تبقىحتى عند بلوغ الميزانية. بيانات أخرى لا تحذف بسبب فشل مؤقت. التعطيل يوقف الجلب؛لتعطيل العرض فورًا اسحب تفعيل/موافقةسجل المصدر، وإلا ينتهي cache خلال TTL.

## دليل الوصول

HTTP200 أعاد **101 عنصر** في التحقق الأول. توزيع type الحقيقي في التشخيص:14 Game و 80 DLC و 6 Early Access و 1 Other. مثال **Contractor: The Clean Up Part 2 (Epic Games) Giveaway**، وسعره الحالي Free؛worth=$4.99 تقديري فقط، ومنصاته PC و Epic Games Store، ونهاية المصدر 2026-12-02 23:59:00 دون timezone منشور. النتائج النهائية للتخزين و REST و Flutter في [التقرير](PHASE7_REPORT.md).
