## المصدر والبائع والاحتفاظ

المصدر ليس بالضرورة البائع. تضيف Migration السابعة علم `isDataSource` وعلاقة Merchant بمصدره ومعرف متجره الخارجي؛ موقع البائع اختياري. عروض CheapShark تتبع البائع الصحيح، ويستخدم `gameID` الرسمي لتجميع عروض المنتج بين بائعي المصدر نفسه. لا دمج بين مصدرين لمجرد تشابه الاسم. البائع في GamerPower مجهول، والمنصة ليست بديلًا عن اسمه. ترتبط SyncRuns بمصدر المزامنة، وسحب موافقته يحجب المحتوى والعروض المرتبطة.

اختير احتفاظ تشغيلي 30 دقيقة لـCheapShark و 10 دقائق لـGamerPower استنادًا إلى رؤوس cache-control المرصودة؛ لا يُنسب ذلك إلى مدة ترخيص منشورة. لا Affiliate خاص أو أرشفة صور أو تاريخ أسعار أو Dataset للبيع. تعرض روابط صور API ضمن العرض مع الإسناد؛ لا تنقل ملكيتها. يجب إعادة مراجعة الشروط قبل توسيع النطاق. درجات CheapShark وتقديرات Worth لا تستبدل تقييم المشروع.

## تشغيل دورة محدودة

```bash
cd backend
npm run db:migrate
npm run cheapshark:sample -- --confirm --limit 20
npm run cheapshark:sync -- --confirm --limit 20
npm run gamerpower:sample -- --confirm --limit 20
npm run gamerpower:sync -- --confirm --limit 20
npm run dev
curl 'http://127.0.0.1:3000/api/v1/deals?view=all&currency=USD&sort=newest'
```

الأمر اليدوي يفعّل المصدر للعملية المقصودة ويهيئ سجل السياسة عند أول استخدام. لا يكتب `.env` ولا يعيد منح موافقة مسحوبة لسجل موجود. العلمان `CHEAPSHARK_ENABLED` و`GAMERPOWER_ENABLED` افتراضيًا false للعامل. لا يشغّل Express أي مزود أو Worker. `CATALOG_INCLUDE_SYNTHETIC=false` افتراضيًا في Backend و`DEMO_MODE=false` في Flutter، وأي تفعيل اصطناعي غير مسموح في الإنتاج.

يحافظ `/deals` على اختيار discounted الافتراضي السابق؛ يضيف `view=all` العروض الصحيحة المجانية دون اشتراط مرجع سعري. يستخدم Flutter Latest و Explore الاختيار all، ويبقى Top و Biggest Discounts مشروطين بالخصم الموثوق. يقارن السعر داخل العملة نفسها. اختيار دولة محددة يستبعد العروض مجهولة السوق بدل اختلاق بلد لها.

للجدولة الاختيارية لـGamerPower، بعد المزامنة اليدوية الأولى:

```bash
WORKER_ENABLED=true WORKER_ALLOW_SYNTHETIC=false GAMERPOWER_ENABLED=true npm run worker:real
```

فاصل المصدر 300 ثانية، و TTL600 ثانية. مصادر حقيقية فقط، دون مزامنة اصطناعية أو زحف CheapShark دوري. التعطيل يوقف الجلب؛ اسحب تفعيل/موافقة Merchant لحجب عروضه فورًا، وإلا تختفي عند TTL.

## التحقق الصريح

```bash
node --import tsx qa/phase7-live.ts --confirm --flutter
```

هذا خارج الاختبارات الافتراضية، ويرسل طلبات فعلية ويكتب بيانات محلية. يقبل 20 عنصرًا كحد لكل مصدر، ثم يقارن المعرفات بعد إعادة المزامنة، ويتحقق من REST بإعداد إنتاج محلي و Flutter headless. خيار `--serve` يبقي API على `127.0.0.1:3337` أثناء اختبار المحاكي حتى Ctrl+C. لا تحفظ الاستجابات الخام، ولا يمثل تقرير القبول كتالوجًا كاملًا أو تاريخ أسعار.

حجب البيانات بـTTL لا يغني عن التنظيف: شغّل `npm run db:purge-expired` أو العامل المستقل لإزالة المحتوى المنتهي. لا يحدث حذف أثناء إغلاق البرنامج. النتائج والأمثلة والقيود في [تقرير المرحلة السابعة](PHASE7_REPORT.md).
