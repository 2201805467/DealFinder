# CheapShark — المرحلة السابعة

مراجعة الوثائق والاتصال الفعلي: **2026-11-19**. هذا مصدر بيانات تجميعي، وليس البائع.

## المصادر الرسمية والإذن

- [توثيق API الرسمي](https://apidocs.cheapshark.com/)، و[مساحة CheapShark الرسمية في Postman](https://www.postman.com/cheapshark/cheapshark-s-public-workspace/documentation/7h22uhl/cheapshark-api).
- [الشروط العامة](https://www.cheapshark.com/terms). الوثائق تسمح باستعمال بيانات التسعير في موقع أو تطبيق دون حساب أو API Key. راجعها مجددًا قبل تغيير نطاق الاستخدام.
- يلزم توجيه المستخدم بروابط CheapShark لكل متجر يتتبعه المصدر، وعدم استبدالها بروابط Affiliate خاصة بنا. الإسناد مستحسن؛ تعرض الواجهة رابطًا فعالًا للمصدر أيضًا.
- يلزم User-Agent مناسب للتطبيق؛ يستخدم العميل `DealFinder/0.1 PortfolioDemo` دون اختلاق عنوان اتصال.
- لا سقف طلبات رقمي منشور في الوثائق المقروءة؛429 يتضمن Retry-After. الوثائق تحذر صراحة من الطلبات الآلية الكثيفة لبناء كتالوج مخزن، وقد تؤدي إلى الحظر الدائم. لذلك **لا جدولة لـCheapShark في هذا المشروع** حتى لو فُعّل، ولا زحف كامل أو طلب تفاصيل لكل منتج. العينة اليدوية المحدودة ليست ادعاء تغطية الكتالوج.

## التحويل والهوية

`GET /api/1.0/stores` يجلب أسماء المتاجر وحالة تفعيلها؛ لا يقدم موقع البائع، فيبقى websiteUrl فارغًا. تحفظ الأسماء في الذاكرة 300 ثانية. `GET /deals?pageNumber=0&pageSize=20` يعيد أسعار USD، ويدعم title و onSale. الترقيم الرسمي يبدأ من 0 وحجم الصفحة الأقصى 60؛ واجهة StoreProvider تبدأ من 1. رأس X-Total-Page-Count يعطي عدد الصفحات **دون إجمالي عناصر دقيق**؛total اختياري ولا يساوي pages×pageSize افتراضيًا.

| حقل المصدر                         | الاستخدام                                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| gameID + storeID                   | هوية عرض ثابتة داخل المصدر، مع السوق والمتغير والعملة في قيد المشروع                           |
| gameID                             | دليل هوية منتج مشترك بين بائعي CheapShark فقط، تحت قفل معاملاتي؛ لا دمج بالأسماء أو بين مصدرين |
| dealID                             | metadata والرابط الحالي؛ تغيّره لا ينشئ عرضًا مكررًا                                              |
| title / thumb                      | الاسم ورابط الصورة الأصلي دون نسخ ملفات الصور على الخادم                                       |
| salePrice / normalPrice / isOnSale | السعر الحالي، ومرجع موثوق فقط إذا كان التخفيض معلنًا والمرجع أكبر من الحالي                     |
| savings                            | لا يعتمد مباشرة؛ يحسب الخصم باستخدام Decimal داخل المشروع                                      |
| dealRating                         | لا يستخدم بدل Deal Score، ولا تتغير أوزان التقييم                                              |
| lastChange                         | حقل تغيير المصدر، لا يُخلط معوقت الجلب؛ التقييم الحالي يستخدم وقت طلب API الفعلي                |

الرابط `https://www.cheapshark.com/redirect?dealID=...` يفك ترميز معرف API مرة واحدة ثم يعيد بناء URL، لتجنب `%252F` بدل`%2F`. ليس رابط المتجر المباشر ولا رابط Affiliate خاصًا بنا. لا يُفترض السوق أو منصة الاسترداد المحددة؛PC هو مجال المصدر ولا يعني Steam لكل عرض. الأسعار المفقودة/غير الصالحة تسجل كعناصر متخطاة ولا تستبدل بقيم مخترعة.

## الاحتفاظ والشبكة

لم نجد مدة قانونية محددة للاحتفاظ أو ترخيصًا مستقلًا لإعادة توزيع الصور. تعتمد النسخة الحالية cache تشغيليًا **1800 ثانية**، موافقًا لرأس cache-control الذي لوحظ للعروض؛ ليس ذلك مدة ترخيص مفترضة. لا تاريخ أسعار دائم أو تنزيل/إعادة استضافة الصور أو نشر Dataset. الصور تعرض من روابط API كجزء من العرض وتبقى حقوقها لأصحابها. يمنع Expiry عرض النص والصورة والسعر القديم؛ التنظيف الموجود يحذف العروض المنتهية ويردّ النصوص المنتهية. شغّل العامل/أمر التنظيف إذا كانت القاعدة قيد الاستخدام؛ إغلاق البرنامج لا ينفذ تنظيفًا خلفيًا سحريًا.

الطلبات عبر حماية HTTPS و DNS الحالية، دون redirect تلقائي، بحجم JSON≤4MiB ومهلة 10s وتباعد≈1.1s داخل العملية. العامل يعالج Retry-After و Exponential Backoff مع Jitter وميزانية الطلبات؛ يحسب طلب المتاجر وكل إعادة محاولة. لا Checkpoint بين جولات هذا الكتالوج المتغير. البيانات القديمة لا تُحذف بسبب فشل الشبكة.

## التشغيل اليدوي

من `backend` بعد `npm run db:migrate`:

```bash
npm run cheapshark:sample -- --confirm --limit 20
npm run cheapshark:sample -- --confirm --limit 5 --query portal
npm run cheapshark:sync -- --confirm --limit 20
```

العينة قراءة فقط. المزامنة opt-in للعملية الحالية، تهيئ سجل السياسة والتصنيفات عند الحاجة، وتحافظ على الموافقة المسحوبة لسجل موجود. `CHEAPSHARK_ENABLED=false` افتراضيًا؛ تشغيل Worker حقيقي يحتاج تفعيلًا صريحًا ولا يبدأ مع Express. لا تعدّل هذه الأوامر`.env`. التوقف عند PAGE_LIMIT/PRODUCT_LIMIT مع حفظ العينة يعني PARTIAL مقصودًا، لا اكتمال الكتالوج. التعطيل يوقف الجلب؛ يمكن تعطيل Merchant نفسه لحجب العروض فورًا، وإلا تختفي عند TTL.

## دليل الاتصال

**قيد مفتوح:** أعاد رابط redirect الرسمي 403 لطلبات HEAD و GET من عميل الفحص، مع نجاح API بـ200. لا يُعتبر الوصول إلى صفحة البائع مؤكدًا. لم نغيّر الرابط أو نحاول تجاوز الرد. المصدر مازال يدويًا محدودًا والتفعيل التلقائي مغلقًا.

التحقق الأول:HTTP200 و 35 متجرًا و 20 عرضًا، دون مفاتيح. مثال حقيقي وقت المراجعة: **Suicide Squad: Kill the Justice League** من **WinGameStore** بسعر USD3.49 مقابل 69.99، وخصم 95.01% محسوب. مثال Deluxe بسعر 4.99 مقابل 99.99. هذه لقطات تحقق مؤرخة وليست ضمانًا للأسعار الحالية. نتائج التخزين وإعادة المزامنة و REST في [تقرير المرحلة](PHASE7_REPORT.md) و`qa-evidence/phase7-real-data.json`.
