# تكامل Best Buy — المرحلة الثانية

الحالة: الكود واختبارات Mock جاهزان؛ لم يُختبر الوصول الحقيقي ولم تُجلب منتجات حقيقية لعدم وجود مفتاح مفعل. لا يعني نجاح الاختبارات قبول الحساب أو صلاحية المفتاح.

## التسجيل والتفعيل

1. افتح [بوابة Best Buy الرسمية](https://developer.bestbuy.com/) واختر Get API Key.
2. سجل حساب المطور بمعلوماتك وراجع شروطه، ثم اتبع تعليمات رسالة البريد لتفعيل المفتاح، وفق [دليل البدء الرسمي](https://bestbuyapis.github.io/api-documentation/#getting-started).
3. أضف القيمة محليًا إلى السطر `BESTBUY_API_KEY=` في `backend/.env`؛ لا تضعها في `.env.example` أو Git أو المحادثة.
4. اترك `BESTBUY_TIMEOUT_MS=10000` أو اضبطه بين 100 و60000 مللي ثانية.

التسجيل والتفعيل ينفذهما صاحب الحساب. لم يُختبر نموذج التسجيل أو زمن الموافقة، ولا يُفترض أن تقديم الطلب يضمن الوصول. مفتاح Products API لا يعني الموافقة على Commerce Gateway؛ الأخير خارج النطاق.

## التشغيل من backend

```powershell
npm run bestbuy:sample -- --limit 20
npm run bestbuy:sample -- --query "usb cable" --limit 20 --page 2
npm run bestbuy:sample -- --all-products --query "monitor" --limit 10
npm run bestbuy:sample -- --limit 20 --cursor "*"
```

يعني `--all-products` إلغاء فلتر التخفيض ضمن نطاق الأجهزة الحالي، وليس استرجاع كل الكتالوج. للمتابعة بالـCursor مرر `nextCursor` من النتيجة مع نفس البحث وحجم الصفحة. لا تجمع `--page` و`--cursor`. يسمح المصدر بحد 100 نتيجة في الصفحة؛ التنفيذ يستخدم صفحات 1 إلى 10، وCursor للنتائج الأعمق، وفق [الوثائق الرسمية](https://bestbuyapis.github.io/api-documentation/#pagination).

كل تشغيل يرسل طلبًا واحدًا فقط، ولا يحاول ملء النتيجة بطلبات إضافية إذا عادت أقل من العدد المطلوب. قد يقل عدد المنتجات الموحدة بسبب تخطي سجلات غير صالحة أو خارج النطاق؛ يظهر `skippedCount`. تعني `partial=true` استجابة جزئية يجب أخذها في الحسبان. لا تحوّل الاستجابة الفارغة إلى عروض مصطنعة.

يعرض الأمر اسم المنتج والأسعار المتاحة ونسبة الخصم والعملة والرابط، مع تمييز النتائج الحقيقية بعبارة `LIVE Best Buy API response`. لا تُطبع هذه العبارة قبل نجاح استلام استجابة صحيحة. الاستجابة الفارغة لا تتحقق بها عينة منتجات فعلية. عدم وجود المفتاح يعيد `CONFIGURATION` ورمز خروج 1 قبل أي اتصال شبكي.

## ربط الحقول

هذه الحقول موثقة ومتوقعة، وليست تقريرًا عن عينة حقيقية تم استلامها:

| النموذج الموحد | المصدر والمعنى |
| --- | --- |
| `externalId` | `sku` |
| `store` | Best Buy، تعريف المصدر |
| `name` | `name` |
| `description` | `shortDescription` إن توفر |
| `imageUrl` | `image` كرابط HTTP(S)، دون تنزيل الصورة |
| `currentPrice` | `salePrice` صالح ومسموح عرضه |
| `originalPrice` | `regularPrice` صالح لا يقل عن السعر الحالي؛ سعر عادي مرجعي وليس تاريخ أسعار مثبتًا |
| `discountPercentage` | الفرق النسبي مقربًا لمنزلتين عند وجود السعرين و`onSale=true` والسعر الحالي أقل من المرجعي |
| `productUrl` | `url` كما يعيده المصدر، بما في ذلك روابط التحويل؛ لا يعاد إنشاؤه |
| `availability` | `onlineAvailability` فقط؛ غيابه لا يثبت عدم التوفر |
| `currency`, `market` | سياق كتالوج BestBuy.com الأمريكي: USD وUS، وليس تحويل عملات أو تأكيد شحن عالمي |
| `fetchedAt` | وقت استلام البيانات محليًا بصيغة ISO؛ ليس تاريخ تحديث السعر عند المتجر |
| `priceRestricted` | يمنع إظهار الأسعار عند قيد غير فارغ أو غير معروف أو عند غياب بيان القيد |

تُحذف الحقول الاختيارية غير الصالحة بدل اختلاق قيم، بما فيها الأسعار الصفرية والسالبة والنصية وغير المحدودة. ترفض السجلات بلا معرف أو اسم صالحين. لا يستخدم `percentSavings` المعلن بديلًا عن الحساب، ولا يمنح الحساب درجة جودة للصفقة. حقول الأسعار والصور والروابط موثقة في [Products API](https://bestbuyapis.github.io/api-documentation/#products-api). سياق الدولار مدعوم أيضًا بـ[إجابة Best Buy عن عملة الأسعار](https://www.bestbuy.com/site/questions/frigidaire-gallery-24-tall-tub-built-in-dishwasher-white/8896593/question/85967c7e-60a0-3b62-8542-2de22ad0a14c).

## القيود المؤثرة على التصميم

بحسب [شروط Best Buy الرسمية](https://developer.bestbuy.com/legal)، الحد المنشور 5 طلبات/ثانية و50000/يوم للمفتاح، والتخزين المؤقت للمحتوى لا يتجاوز 72 ساعة لغرض تسريع العرض. لا توجد هنا قاعدة لتخزين المنتجات أو الصور أو تاريخ الأسعار. يلزم لاحقًا حذف المحتوى المنتهي أو تحديثه ضمن السياسة، مع إسناد المصدر وحفظ الروابط وإشعارات الملكية. لا تحفظ مخرجات العينة كأرشيف دائم. تحليل البيانات لمصلحة تجار آخرين واستخدام محتوى الألعاب والأفلام والموسيقى له قيود؛ التنفيذ الحالي للأجهزة `HardGood` فقط. يجب مراجعة أهلية الاستخدام قبل التوسع، والحصول على اتفاق إضافي حيث تتطلبه الشروط.

وفق [الوثائق](https://bestbuyapis.github.io/api-documentation/)، روابط الاستجابة قد تنتهي بعد 7 أيام؛ هذا لا يمدد مهلة التخزين. قيود MAP/ICR تمنع إظهار بعض الأسعار، والتوفر عبر الإنترنت لا يثبت الشحن لدولة المستخدم. لا ينفذ هذا التكامل تحويل عملة أو فحص شحن.

المزود يفصل بدايات الطلبات بـ250ms على الأقل لكل instance. لا يضمن الحصة المشتركة بين عمليات أو مفاتيح مستخدمة في تطبيقات أخرى، ولا يحصي السقف اليومي. عند التوسع يلزم تنسيق ذلك مركزيًا ضمن مرحلته. `403` يعامل كالتباس بين المفتاح والحصة دون إعادة محاولة؛ `429` يحترم `Retry-After` أو يستخدم تهدئة 60 ثانية. لا توجد إعادة محاولات تلقائية تستهلك الحصة. الأخطاء لا تتضمن المفتاح أو رابط الطلب أو نص الاستجابة، والطلبات لها مهلة وتمنع اتباع التحويلات.
